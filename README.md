📌 Sobre o Projeto

Este projeto consiste em um site de portfólio pessoal responsivo e moderno, criado com o objetivo de apresentar minha trajetória como Jovem Aprendiz de TI, minhas habilidades técnicas, interesses e projetos desenvolvidos durante minha formação.

O site busca reunir, de forma organizada e visualmente agradável, informações profissionais e acadêmicas, além de facilitar o contato e o acesso aos meus perfis profissionais.

🚀 Como Executar o Projeto Localmente
Clone o repositório ou faça o download dos arquivos do projeto.
Acesse a pasta onde os arquivos foram baixados.
Certifique-se de que o arquivo style.css esteja na mesma pasta que o index.html.
Abra o arquivo index.html em qualquer navegador.
Para facilitar o desenvolvimento, também é possível utilizar a extensão Live Server no Visual Studio Code.
